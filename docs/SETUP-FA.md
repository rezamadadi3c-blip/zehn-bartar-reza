# راه‌اندازی هوش ابری چندمسیره ذهن برتر

این نسخه از سه مسیر برای پاسخ متنی استفاده می‌کند:
1. Cloudflare Workers AI (مسیر اصلی)
2. Google Gemini 2.5 Flash-Lite (جایگزین)
3. Groq GPT-OSS-20B (جایگزین دوم)

در صورت خطای مسیر اصلی، برنامه مسیرهای بعدیِ دارای کلید را امتحان می‌کند. کلیدها فقط باید در سمت سرور ذخیره شوند؛ هرگز آن‌ها را داخل فایل HTML، APK یا پیام گفتگو قرار ندهید.

## کلید Gemini (مسیر جایگزین پیشنهادی)

1. به https://aistudio.google.com/apikey بروید.
2. با حساب Google وارد شوید و یک API key بسازید.
3. در Cloudflare به Workers & Pages بروید و Worker با نام `zehn-bartar-reza` را باز کنید.
4. Settings → Variables and Secrets → Add را انتخاب کنید.
5. نوع مقدار را Secret بگذارید؛ نام: `GEMINI_API_KEY` و مقدار: کلید ساخته‌شده.
6. ذخیره کنید.

مدل استفاده‌شده `gemini-2.5-flash-lite` است. سهمیه رایگان و محدودیت‌ها تابع سیاست و وضعیت حساب Google هستند؛ رایگان بودن به معنی نامحدود بودن نیست.

## کلید Groq (جایگزین دوم و تبدیل صوت)

1. به https://console.groq.com/keys بروید.
2. وارد حساب شوید و API key بسازید.
3. در همان صفحه Variables and Secrets در Cloudflare یک Secret دیگر اضافه کنید:
   نام: `GROQ_API_KEY`
   مقدار: کلید Groq.
4. ذخیره کنید.

Groq برای پاسخ متنی و تبدیل صوت به متن به‌عنوان مسیر جایگزین استفاده می‌شود. محدودیت‌های حساب در صفحه Limits کنسول Groq نمایش داده می‌شود.

## اصلاح خطای استقرار Cloudflare

در GitHub مخزن ذهن برتر به Settings → Secrets and variables → Actions بروید.
Secret با نام `CLOUDFLARE_ACCOUNT_ID` را ویرایش کنید و مقدار واقعی Account ID را از داشبورد Cloudflare کپی کنید. این مقدار با Zone ID یا شناسه Worker فرق دارد.

برای پیدا کردن آن:
- داشبورد Cloudflare را باز کنید.
- وارد Workers & Pages شوید.
- در بخش Account Details، مقدار Account ID را کپی کنید.
- همان مقدار را در Secret با نام دقیق `CLOUDFLARE_ACCOUNT_ID` ذخیره کنید.

توکن API را در گفتگو یا کد قرار ندهید.

## آزمایش

پس از ذخیره Secretها و موفق شدن استقرار، در برنامه دکمه «آزمایش واقعی اتصال هوش ابری» را اجرا کنید. مسیر انتخاب‌شده در پاسخ تشخیصی گزارش می‌شود.

## وضعیت قابلیت‌ها

- گفتگو: Cloudflare، سپس Gemini، سپس Groq.
- تحلیل تصویر: Cloudflare Gemma، سپس Gemini در صورت تنظیم کلید.
- تبدیل صوت به متن: Cloudflare Whisper، سپس Groq Whisper.
- ساخت تصویر: فعلاً Cloudflare Workers AI؛ برای مسیر جایگزین تصویر هنوز سرویس دوم تنظیم نشده است.
- جست‌وجوی وب: Brave و Tavily در صورت تنظیم کلید؛ در غیر این صورت دانشنامه فارسی به‌عنوان مسیر پایه.

هیچ‌یک از این سرویس‌ها تضمین دسترسی دائمی یا مصرف نامحدود رایگان نمی‌دهند.
