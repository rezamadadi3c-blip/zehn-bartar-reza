# ذهن برتر — نسخه Cloudflare Workers

این پروژه یک دستیار فارسی‌زبان با رابط قابل نصب روی موبایل (PWA) و چت ابری است.

## استقرار
- Root directory: /
- Build command: خالی
- Deploy command: npx wrangler deploy

## هوش مصنوعی ابری
اتصال اصلی از طریق Cloudflare Workers AI و binding با نام `AI` انجام می‌شود. تنظیم آن در `wrangler.toml` قرار دارد و به کلید API جداگانه نیاز ندارد.
- مدل پیش‌فرض: `@cf/meta/llama-3.1-8b-instruct`
- سهمیه رایگان اعلام‌شده Cloudflare: 10,000 Neurons در روز در Workers Free؛ مصرف بیشتر از حد رایگان در پلن رایگان متوقف می‌شود. جزئیات و مدل‌های مشمول ممکن است تغییر کنند.
- می‌توان در صورت نیاز از سرویس سازگار با OpenAI به‌عنوان مسیر جایگزین با Secret به نام `AI_API_KEY` استفاده کرد.

## امنیت
کلیدهای API را در GitHub، فایل‌های عمومی یا چت قرار ندهید. در صورت استفاده از سرویس جایگزین، کلید فقط به‌صورت Secret در Cloudflare ثبت شود.

## وضعیت قابلیت‌ها
نسخه فعلی شامل چت متنی ابری، رابط فارسی راست‌چین و قابلیت نصب PWA است. حالت آفلاین فقط پوسته برنامه را نگه می‌دارد؛ پاسخ هوش مصنوعی به اینترنت و سهمیه سرویس وابسته است. صدا، تصویر، تحلیل فایل و APK بومی هنوز پیاده‌سازی نشده‌اند.
