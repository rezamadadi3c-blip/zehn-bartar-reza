# ذهن برتر رضا — نسخهٔ ۱٫۰ (نمونهٔ کامل آفلاین)

این پروژه یک برنامهٔ اندرویدی فارسی برای ثبت مکالمه، بررسی مقدماتی مرزهای شخصی و نگهداری گزارش‌ها روی همان گوشی است.

## قابلیت‌ها
- ورود دستی متن مکالمه و تحلیل مقدماتی با قواعد محلی؛ تحلیل برای پول و تعهد، فشار زمانی، نقل‌قول‌های تأییدنشده، بیان مرز، عذرخواهی و عبارت‌های تهدیدآمیز.
- تعریف مرزهای شخصی توسط کاربر و نمایش آن‌ها کنار گزارش.
- ذخیرهٔ متن و گزارش با تاریخ، نمایش گزارش‌های قبلی و حذف جداگانهٔ هر مورد.
- اشتراک‌گذاری گزارش آخر با انتخاب خود کاربر.
- پاک‌کردن تمام داده‌های محلی برنامه.
- درخواست تشخیص گفتار فارسی فقط پس از لمس دکمه و گرفتن مجوز میکروفون؛ دکمهٔ توقف نیز دارد.

## حریم خصوصی و محدودیت‌ها
- تحلیل متن و ذخیره‌سازی در این نسخه به‌صورت محلی انجام می‌شود و برنامه برای تحلیل، درخواست شبکه ندارد.
- تشخیص گفتار اندروید از سرویس نصب‌شده روی گوشی استفاده می‌کند؛ ممکن است به اینترنت یا پردازش بیرونی وابسته باشد. اگر استفاده از سرویس بیرونی نمی‌خواهی، متن را دستی وارد کن.
- برنامه مکالمه را در پس‌زمینه ضبط یا شنود نمی‌کند. برای ضبط صدای افراد دیگر باید رضایت آن‌ها را بگیری و قوانین محل را رعایت کنی.
- تحلیل، قاعده‌محور و مقدماتی است؛ این نسخه مدل زبانی بزرگ، هوش مصنوعی مولد، تشخیص نیت یا دروغ، مشاورهٔ حقوقی/روان‌شناختی و تضمین تصمیم درست ندارد.

## ساخت APK
1. یک رایانه با Android Studio و اتصال اینترنت برای دریافت ابزارهای ساخت لازم است.
2. پوشهٔ پروژه را در Android Studio باز کن.
3. اجازه بده Gradle همگام‌سازی شود و Android SDK 35 نصب باشد.
4. از مسیر **Build → Build APK(s)** فایل APK آزمایشی را بساز.
5. مسیر معمول خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## وضعیت آزمون
این بسته سورس پروژه است، نه APK. در محیط تولید این فایل‌ها Android SDK/Gradle در دسترس نبود؛ بنابراین کامپایل، نصب و آزمایش روی Samsung A32 انجام نشده و نمی‌توانم سازگاری نهایی را تضمین کنم. قبل از استفادهٔ واقعی باید روی گوشی آزمایش شود.
